# Ensomi Research

Read `README.md` and `research/README.md` before editing. This repository owns
the research index and curated archive descriptions; source repositories own
maintained implementations and their reports.

- Keep entries small and grounded in linked evidence. Use the entry template.
- Distinguish observed, training, evaluation and release commits. Pin evidence
  to full commits and label moving project links.
- Attribute source-reported checks. Never infer reproducibility from a source
  snapshot, release tag, existing script or successful inference example.
- Keep private notes, datasets, audio and per-item records out. Do not copy
  source code or large artifacts as routine index maintenance.
- Add automation or snapshot assembly only for a concrete, authorized need.
- Do not invent citations, authors, DOIs or licence grants.
- For documentation changes, check relative links, cited versions and
  `git diff --check`. Run research commands only when the task calls for them.

## Maintaining the index

Each entry should name its question, source and artifact identities, evidence
and limitations. Use the [template](../templates/research-entry.md); mark a
missing item as unknown or unavailable rather than filling it by inference.
Keep the distinction between locating sources, repeating a command and
reproducing a stated result. A successful inference example does not establish
that training or evaluation can be repeated.

Use commit links for evidence about a particular version. Keep useful branch
or project links labelled as moving entry points. When a result is superseded,
retain its evidence and link its successor instead of silently changing the
version that an earlier statement describes.
